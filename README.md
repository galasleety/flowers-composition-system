# Программное средство «Композиции и компоненты цветочных букетов»

Информационная система для систематизации флористических данных и автоматизации проектирования букетов с автоматической проверкой совместимости компонентов.

## Стек технологий
* Язык программирования: C++
* Фреймворк: Qt (Qt Creator)
* СУБД (Оригинальная архитектура): MySQL
* СУБД (Рабочая сборка): SQLite

## Функциональные возможности
* **Конструктор букетов:** Визуальная сборка композиций с программной валидацией совместимости добавляемых элементов (эстетическая и биологическая совместимость).
* **Каталог:** Просмотр и фильтрация цветов, стаффажа, упаковки и аксессуаров по характеристикам и сезонности.
* **Профиль пользователя:** Сохранение сгенерированных композиций, ведение избранного и текстовых заметок.
* **Панель администратора:** CRUD-операции для каталога, справочников, правил совместимости компонентов и управление правами доступа пользователей.

## Архитектура базы данных

Изначально бизнес-логика приложения была спроектирована под **MySQL** с вынесением части вычислений на уровень СУБД. В директории `database/mysql_architecture_and_triggers.sql` сохранен оригинальный DDL-код, включающий:
* **Триггер:** Проверка правил совместимости перед добавлением записи в связующую таблицу состава букета (`trg_CheckCompatibility_BeforeInsert`).
* **Хранимые процедуры:** Инкапсуляция транзакционной логики добавления новых сущностей в связанные таблицы.
* **Пользовательские функции и представления:** Оптимизация выборок и сокращение количества JOIN в приложении.

**Примечание по сборке:** В целях обеспечения портативности и возможности локального запуска без развертывания сервера MySQL, текущая рабочая версия в репозитории использует встроенную БД **SQLite**.

## Запуск проекта
1. Клонировать репозиторий.
2. Открыть файл `flowers.pro` в среде Qt Creator.
3. Выполнить сборку проекта. Файл локальной базы данных SQLite (`flowers.db`) находится в директории проекта и подключается автоматически.
